# YAMINI × AARRAN
### A Mother’s Archive of Her Son’s Childhood

> *“Some memories were never posted. But they were never forgotten.”*
> 
> *“My purpose in life is him.”* — Yamini

---

## 🎬 Project Overview
An original, cinematic, Netflix-inspired personal streaming archive website created by **Yamini** for her son **Aarran**.

Built with React, TypeScript, and modern cinematic CSS aesthetics:
- Dominant `#141414` streaming atmosphere with pure black letterboxing.
- Original glowing **A** Monogram identity with dimensional lighting.
- Intelligent media catalog preserving face and interaction focal points.
- Original background soundtrack (*Taylor Swift — Never Grow Up*) with real-time volume ducking during video playback.

---

## ✨ Features & Narrative Arc

1. **Original Streaming Intro (`<IntroSequence />`)**:
   Pure black $\rightarrow$ glowing text reveals $\rightarrow$ *“YAMINI PRESENTS”* $\rightarrow$ red line draws the original cinematic **A** monogram $\rightarrow$ reveals *AARRAN: AN ORIGINAL STORY BY MOM*.
2. **“Who’s Watching?” Profile Picker (`<ProfileSelection />`)**:
   Streaming profile selection with personalized perspective cards for *Yamini*, *Aarran*, *Lil Eggs 🥚❤️*, and *Memories*.
3. **“Press Play On His Childhood” (`<PressPlayExperience />`)**:
   One-click audio unlock launching a 5-stage opening photo montage from infancy to present day.
4. **Cinematic Hero (`<HeroSection />`)**:
   Hero portrait with left-to-right gradient fade, metadata badges, Play Story, and More Info actions.
5. **Horizontal Continue Watching Shelf (`<ContinueWatchingShelf />`)**:
   9 sequential episodes (**EP 01** to **EP 09 TEEN**) with progress bars, hover expansion cards, and durations.
6. **The Unposted Archive & Vault (`<UnpostedArchive />` & `<MemoryVaultModal />`)**:
   *“Not everything made it to social media. But everything made it into my heart.”*
   Full vault modal with category filters (`ALL`, `THE LITTLE YEARS`, `PORTRAITS`, `BIRTHDAYS`, `TRAVEL`, `ORIGINAL FILMS`) and live search.
7. **Mom & Me (`<MomAndMe />`)**:
   Emotional chapter centered around Yamini's core quote: *“My purpose in life is him.”*
8. **Lil Eggs Inside Joke (`<LilEggs />`)**:
   Interactive **[CRACK THE EGG 🥚]** button with cracking animation & confetti revealing *“Mom ❤️ Aarran: Each other's lil eggs forever.”*
9. **December Special & December Mode (`<DecemberSpecial />`)**:
   Celebrating their shared December birthday month with Spider-Man cake and interactive **[🎂 MAKE A WISH]** candle blowout.
10. **Movie Nights (`<MovieNights />`)**:
    Cinema pass ticket card launching a private screening theater mode playing home movies.
11. **Places We Went Together (`<TravelTogether />`)**:
    Connecting the journey from the replica Eiffel Tower to the real Eiffel in Paris and ocean beaches.
12. **Then $\rightarrow$ Now Split Slider (`<ThenNowSlider />`)**:
    Interactive drag slider comparing baby Aarran with older Aarran (*“Different chapters. Same lil egg.”*).
13. **Hold to Grow (`<HoldToGrow />`)**:
    Press-and-hold interactive fast-forward through childhood stages.
14. **Digital Polaroid (`<DigitalPolaroid />`)**:
    Nostalgic tap-to-develop photo frame.
15. **Memory Shuffle (`<MemoryShuffle />`)**:
    **[SURPRISE ME ❤️]** randomizer with reel animation.
16. **Mom’s Watchlist (`<MomsList />`)**:
    Local storage-backed *My List ❤️* saved by Mom.
17. **Episode 09: TEEN & Next Season Teaser (`<Episode09TeenModal />` & `<NextSeasonTeaser />`)**:
    Buffering stops at **99%** with the emotional reveal: *“Why isn't it loading? Because this chapter hasn't happened yet... See you in the next season, Aarran.”*
18. **Final Message & End Credits (`<FinalMessage />` & `<EndCredits />`)**:
    *“Through every version of you... 'My purpose in life is him.' — Yamini”* and cinematic rolling credits.
19. **Secret Easter Egg Hunt (`<SecretEasterEggModal />`)**:
    Hidden eggs in the navbar and footer revealing their special bond.
20. **Floating Remote (`<MemoryRemote />`) & Timeline Ribbon (`<TimelineRibbon />`)**:
    Interactive D-pad streaming remote and progress ribbon with an open teen circle.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation
```bash
npm install
```

### Run Locally
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build for Production
```bash
npm run build
```
Preview production build:
```bash
npm run preview
```
